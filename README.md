# haxgad.com

Personal website of Harsh Gadodia — [haxgad.com](https://haxgad.com)

## Built with

- [Astro](https://astro.build)
- [TailwindCSS](https://tailwindcss.com/) + [DaisyUI](https://daisyui.com/)
- Based on the [Astrofy](https://github.com/manuelernestog/astrofy) template

## Local development

```bash
npm install
npm run dev
```

The site will be available at `http://localhost:4321`.

## Build

```bash
npm run build
```

## Deployment

Deployed to [GitHub Pages](https://pages.github.com/) via GitHub Actions on push to `gh-pages`.
